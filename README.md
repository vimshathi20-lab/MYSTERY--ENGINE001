# 🔎 Mystery Engine — The Veil Files

**Every clue hides a truth. Every truth leaves a trace.**

Mystery Engine is a Java-based interactive detective game where players investigate mysterious cases, examine evidence, analyze contradictions, and uncover the truth behind interconnected mysteries.

Step into the investigator's role, question the evidence, and discover how seemingly separate cases connect through a hidden trail.

## 🎮 Features

- 🕵️ **Interactive Investigations** — Explore cases through a graphical user interface.
- 🔍 **Clue-Based Gameplay** — Examine evidence and discover what the clues prove—and what they don't.
- 🧩 **Multiple Mystery Cases** — Investigate three interconnected cases.
- 👥 **Suspect Analysis** — Evaluate suspects and compare their statements with the evidence.
- 🗂️ **Story Progression** — Uncover connections between cases as the investigation advances.
- 🌑 **Dark-Themed Interface** — Play through a custom Java Swing interface.

## 📁 The Cases

### Case #001 — The Midnight Archive
A rare manuscript disappears from a locked archive. Investigate access records, physical evidence, and a suspicious replacement page to uncover the truth.

### Case #002 — The Thirteenth Hour
A mysterious disappearance at a museum raises questions about a blackout, a replica, and an unusual conservation transfer.

### Case #003 — The Silent Witness
An altered financial ledger, conflicting records, and an anonymous threat lead to a deeper investigation into evidence manipulation.

**The Veil Files** connects these investigations through a recurring reference: P-17.

## 💻 How to Run

### Prerequisites
Install a Java Development Kit (JDK) on your computer.

### Steps

1. Clone or download this repository.
2. Open a terminal in the folder containing `Main.java`.
3. Compile the program:

   ```bash
   javac Main.java
   ```

4. Run the game:

   ```bash
   java Main
   ```

The Mystery Engine window should open, allowing you to begin the investigation.
